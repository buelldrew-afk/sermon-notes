# Sermon Notes: rules for Claude

Weekly fill-in sermon notes pages (replacing Subsplash). README.md has the workflow and notes.txt format.

- Source of truth is `sermons/<date>-<title>/notes.txt`; `docs/` is generated by `tools/build.py`. Never hand-edit `docs/`.
- New week: run `tools/from_slides.py <pptx> <sunday-date>`, then finish notes.txt. Scripture text and "See also" refs come from Drew's Subsplash page or outline; never invent them. Use ESV wording as Drew does.
- Blanks: only where Drew puts them (Subsplash "keyword" blanks, or his outline). If he gave none, ask, or suggest a key word per point and say so.
- Preview with the `sermon-notes` entry in the parent `.claude/launch.json` (port 8642), check at mobile width, and show Drew before any push.
- Ask Drew before creating repos, pushing, or publishing. Never delete Drew's files.
